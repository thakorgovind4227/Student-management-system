# Student Management System

## Description
A console-based Student Management System built using Python. It stores student information in a JSON file and allows users to manage student records through a menu-driven interface.

## Features
- Display all student details
- Add new students
- Search students by roll number
- Update student marks
- Delete student records
- Store student data in a JSON file
- Colorful terminal output for student details

## Technologies Used
- Python
- JSON

## Project Files
- `main.py` — Contains the main program logic.
- `students.json` — Stores student records.

## How to Run

1. Install Python on your computer.
2. Clone this repository or download the project files.
3. Make sure `main.py` and `students.json` are in the same folder.
4. Open the terminal in the project folder.
5. Run the following command:

   ```
   python main.py
   ```

## Usage
Run the program and select an option from the menu to display, add, search, update, or delete student records.
